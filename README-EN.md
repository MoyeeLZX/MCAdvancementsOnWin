# Introduction
## Suitable on Where
+ A normally **Windows 10 or newer system**.
## What will this thing do
When the program is running, it will check the processes and windows' title that are running on Windows by the user. If certain conditions are met, it triggers a feature similar to the [advancements](https://minecraft.wiki/w/Advancement) in [Minecraft Java Edition](https://minecraft.wiki/w/Java_Edition), while simultaneously playing a [sound effect](https://minecraft.wiki/images/transcoded/Challenge_complete.ogg/Challenge_complete.ogg.mp3).
